# kaomoji studio

A web app for building custom kaomojis. Click on each part to swap it and create your own combination.

## Features

- Click any part to edit (brackets, arms, eyes, mouth, suffix)
- 12 presets to use as a starting point
- Randomize to generate unexpected combinations
- Save your favorites to a history list
- Copy with one click

## Build with

- HTML, CSS, JavaScript (vanilla)
